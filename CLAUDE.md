# Ring Racers Worldwide

Fork de Ring Racers (Kart Krew) qui ajoute un netcode à prédiction côté client,
en développement. Branche de travail : `rollback-netcode`.

La documentation du projet et les consignes pour les agents sont dans un dépôt
privé, `RingRacers_Worldwide-notes`, cloné à côté de celui-ci. Les lire avant
toute chose ; s'il est absent, demander au porteur du projet de le cloner.

- **Ne jamais lancer le jeu ni un test sans son accord explicite, à chaque fois.**
- **Ce dépôt est public** : n'y ajouter ni info personnelle ni doc de
  développement. Elles vont dans le dépôt privé.
