# Ring Racers Worldwide

Fork de Ring Racers (Kart Krew) qui ajoute un netcode à prédiction côté client,
en développement. Branche de travail : `rollback-netcode`.

Ici, trois docs : [docs/WORLDWIDE.md](docs/WORLDWIDE.md) (état courant en
tête, puis le journal), [docs/ROADMAP.md](docs/ROADMAP.md) (la suite) et
[docs/COMMANDS.md](docs/COMMANDS.md) (les commandes console). Le reste de la
documentation et les consignes complètes pour les agents sont dans un dépôt
privé, `RingRacers_Worldwide-notes`, cloné à côté de celui-ci. Les lire avant
toute chose ; s'il est absent, demander au porteur du projet de le cloner.

- **Ne jamais lancer le jeu ni un test sans son accord explicite, à chaque fois.**
- **Ce dépôt est public** : aucune info personnelle (chemins locaux, nom
  d'utilisateur, prénom). Les trois docs d'ici sont **identiques** à celles du
  dépôt privé : toute modification se copie de l'autre côté dans la même
  session.
